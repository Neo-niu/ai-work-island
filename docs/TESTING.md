# AI 工作岛测试与发布闸门

## 目标

证明用户拿到的安装版可用，而不只证明内部函数正确。

## 自动闸门

运行：

```bash
./script/verify_release_candidate.sh
```

自动覆盖：Swift 逻辑测试、20 个胶囊视觉基线、构建安装、严格签名、单实例、数据源诊断和安装版辅助功能树。

更新视觉基线必须是有意的界面变更，并在人工查看 PNG 后执行：

```bash
RECORD_VISUAL_SNAPSHOTS=1 swift test --disable-sandbox \
  --scratch-path /tmp/ai-work-island-visual-tests \
  --filter FloatingCapsuleSnapshotTests
```

## 安装版黑盒验收

Xcode 与 Appium Mac2 已配置。先运行当前自动化冒烟集：

```bash
./script/run_appium_smoke.sh
```

该脚本以真实安装版完成胶囊读取、展开、核心入口回读、输入写入与清理、离开回缩、三轮竞态重放和截图回读。下面完整清单中尚未自动化的项目继续人工验证。

每次正式发布逐项验证；任何关键项失败均停止发布。

- [ ] 冷启动只出现一个 108×38pt 胶囊，进程数为 1。
- [ ] 鼠标进入胶囊后面板展开，移入面板不会误收起。
- [ ] 鼠标离开面板 0.5 秒后胶囊恢复，不消失、不反复展开。
- [ ] 连续快速进入、离开、再次进入，不触发旧动画 completion 隐藏窗口。
- [ ] 点击胶囊只展开面板，不打开 Finder 或历史产出。
- [ ] 面板拖动、四边缩放和贴边后，展开与胶囊锚点一致。
- [ ] 多显示器、全屏空间和切换桌面后窗口仍可见且位于正确屏幕。
- [ ] 清爽/详细模式切换后，任务卡无文字溢出或异常增高。
- [ ] 新任务文字发送创建持久会话，并在 Codex 索引中出现。
- [ ] 新任务图片粘贴、删除和仅图片发送均正确，临时文件会清理。
- [ ] 卡片续接发送到该卡片的稳定 thread ID，不串到最近会话。
- [ ] “转到 Codex”打开精确会话，运行中的工作岛任务先安全释放。
- [ ] 工作岛重启时后台任务不中断，完成后状态能回读。
- [ ] Edge/Codex/自动化状态源不可用或文件损坏时诚实降级，不误报正常。
- [ ] 解压正式 ZIP 后版本、签名、启动、胶囊和主要交互与本机构建一致。

## 当前环境边界

本机已安装 Xcode 26.6、Appium 3.6.0 和 Mac2 4.2.0。Appium Doctor 的必需检查全部通过；“无需认证的 Automation Mode”仍为可选警告，当前会话可以正常建立，因此未降低系统认证安全级别。多屏、跨重启任务、精确会话跳转和正式 ZIP 首装仍需继续自动化或保留人工验收。
