# AI工作岛测试与发布闸门

## 目标

证明用户拿到的安装版可用，而不只证明内部函数正确。

## 自动闸门

运行：

```bash
./script/verify_release_candidate.sh
```

自动覆盖：Swift 逻辑测试、20 个胶囊视觉基线、构建安装、严格签名、单实例、数据源诊断和安装版辅助功能树。

更新视觉基线必须是有意的界面变更，并在人工查看 PNG 后执行：

```bash
RECORD_VISUAL_SNAPSHOTS=1 swift test --disable-sandbox \
  --scratch-path /tmp/ai-work-island-visual-tests \
  --filter FloatingCapsuleSnapshotTests
```

## 安装版黑盒验收

不运行 Appium Mac2：仅建立会话也会触发 macOS `testmanagerd` 的第三方输入法授权弹窗。安装版交互改用人工或 Computer Use 回读；输入、粘贴、展开回缩和竞态行为由 Swift 回归测试覆盖。

每次正式发布逐项验证；任何关键项失败均停止发布。

- [ ] 冷启动只出现一个 108×38pt 胶囊，进程数为 1。
- [ ] 鼠标进入胶囊后面板展开，移入面板不会误收起。
- [ ] 鼠标离开面板 0.5 秒后胶囊恢复，不消失、不反复展开。
- [ ] 连续快速进入、离开、再次进入，不触发旧动画 completion 隐藏窗口。
- [ ] 点击胶囊只展开面板，不打开 Finder 或历史产出。
- [ ] 面板拖动、四边缩放和贴边后，展开与胶囊锚点一致。
- [x] 多显示器、全屏空间和切换桌面后窗口仍可见且位于正确屏幕。2026-08-21 在 4K 主屏与内建 Retina 双屏在线环境验证屏幕拓扑；屏幕重配、失效位置回收、全屏层级和各边吸附回归通过。
- [ ] 清爽/详细模式切换后，任务卡无文字溢出或异常增高。
- [ ] 新任务文字发送创建持久会话，并在 Codex 索引中出现。
- [ ] 新任务图片粘贴、删除和仅图片发送均正确，临时文件会清理。
- [ ] 卡片续接发送到该卡片的稳定 thread ID，不串到最近会话。
- [x] “转到 Codex”打开精确会话，运行中的工作岛任务先安全释放。2026-08-21 目标线程 `01a023f4-9021-7790-b7a1-cef000920976` 同时存在于工作岛注册表、Codex 线程索引和稳定 ID 深链；所有入口统一路由、退订与所有权释放回归通过。
- [x] 工作岛重启时后台任务不中断，完成后状态能回读。2026-08-21 实测 UI PID `34953 → 44328`，独立 App Server PID 保持 `41987`；同一线程随后完成并回读 `RESTART_CONTINUITY_PASS`。
- [ ] Edge/Codex/自动化状态源不可用或文件损坏时诚实降级，不误报正常。
- [ ] 解压正式 ZIP 后版本、签名、启动、胶囊和主要交互与本机构建一致。（用户已明确移出本次验收范围。）

## 当前环境边界

本机已安装 Xcode 26.6。Appium 3.6.0 和 Mac2 4.2.0 虽可建立会话，但因会触发 `testmanagerd` 输入法授权，不纳入验收。多屏、跨重启任务和精确会话跳转使用人工/Computer Use 与系统状态证据验收；正式 ZIP 首装已按用户要求移出范围。
